- ✅ 精美的网页界面，可直接查看赛程
- ✅ 支持下载和订阅

## 🚀 使用方法

### 方法1: 直接下载

1. 打开 `index.html` 文件（在浏览器中打开）
2. 点击 "📥 下载ICS日历文件" 按钮
3. 在你的日历应用中选择导入
4. 选择下载的 `.ics` 文件

### 方法2: 复制订阅链接（需要托管）

如果你有服务器或GitHub Pages，可以：

1. 将所有文件上传到服务器
2. 复制 `f1_2026.ics` 的URL
3. 在日历应用中选择"订阅日历"
4. 粘贴URL即可
