## 🚀 使用方法

### 方法1: 直接下载

**仅正赛版本**（22场比赛）：
1. 打开 `index.html` 文件（在浏览器中打开）
2. 点击 "📥 仅正赛日历" 按钮
3. 在你的日历应用中选择导入
4. 选择下载的 `f1_2026.ics` 文件

**完整赛程版本**（110场比赛，包含所有环节）：
1. 点击 "📥 完整赛程（含练习/排位/冲刺赛）" 按钮
2. 在你的日历应用中选择导入
3. 选择下载的 `f1_2026_full.ics` 文件

### 方法2: 复制订阅链接（需要托管）

如果你有服务器或GitHub Pages，可以：

1. 将所有文件上传到服务器
2. 复制 ICS 文件的URL
3. 在日历应用中选择"订阅日历"
4. 粘贴URL即可
